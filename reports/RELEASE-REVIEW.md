| 打包 | npm 通过 Node 启动 npm-cli.js，不直接执行 Windows .cmd；无开发依赖安装后执行功能模拟请求及帮助检查 |

## 证据范围

- 113 个接口：339 个成功/业务失败/HTTP 失败传输子用例，另有 28 个确认阻断子用例。
- 74 个命名业务命令：73 个独立 HTTP 映射案例，另有 adb-info 多请求分页场景。
- 异步场景模拟区分 accepted、pending、ready 和 business failure，不证明真实设备完成启动。
- 完整测试报告包含父测试与子测试事件；事件总数不是接口数，不用测试数量替代覆盖深度。
- macOS：Node 22.12.0（声明的最低版本）、22.23.3、24.21.0 完整验证通过。
- 安装包仅 27 个发布文件，无运行时 npm 依赖；5 项帮助检查及 3 项安装后功能模拟检查。
- 本项目实际打包、临时安装后的命令完成 17 项实机只读检查；详见 live-package-readonly.json。
  此证据不同于此前官方 ml-cli 的 17 项预检。未保存资源明细、余额或凭据。
- npm audit 本次查询：32 个依赖，0 个已知漏洞；并非安全无风险保证。
- 根 Skill 和 setup Skill 的 quick_validate 均通过。

机器证据位于 endpoint-matrix.json、test-events.jsonl、tests.tap、package.json；
Node 24 与最低 Node 22 的结果分别保存在 node24/、node22-min/。
接口请求 fixture 使用上游规范；其已有 pattern/format 例外见 references/openapi.md。
通用响应测试仍使用模拟 envelope，不声称验证全部真实业务响应或完整运行时 Schema。
